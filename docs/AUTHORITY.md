# Authority

The standing contracts in `docs/` govern. Chat and attachments change them
only where Marcus explicitly adopts a specific part; adoption extends only to
that named part.

Use `PRICING_MATH.md`, `SETTLEMENT_RUNS.md`, `BILLING_CONTRACTS.md`, and
`ARCHITECTURE.md` for domain behavior. `STATEMENT.md` governs its screen's
roles, labels, references, and visibility.
